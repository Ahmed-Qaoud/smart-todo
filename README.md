# Smart To-Do List 🧠✨

A premium, intelligent To-Do List web application built with **React + TypeScript + Vite**, featuring:

- **Glassmorphism Dark Mode UI**: Modern, sleek, and responsive design.
- **Natural Language Parsing (NLP)**: Add tasks using plain text like "Prepare presentation tomorrow at 2pm for 1 hour".
- **Smart Task Suggestions**: Automatic subtasks, category detection, and optimal time-block recommendations.
- **Gamification**: Earn points, track streaks, level up, and unlock badges for completed tasks.
- **Intelligent Scheduling**: Visual timeline and automatic conflict detection for overlapping tasks.
- **Daily Analysis**: Track your daily productivity and see how much you accomplished.

---

## 🔧 Features

### Core
- Add tasks using natural language.
- Auto-parse date, time, duration, and priority.
- AI-generated subtasks for large milestones.
- Categorization (Work, Personal, Fitness, etc.).
- Timeline with conflict detection and suggested rescheduling.

### Gamification
- Points system (+10 for normal, +20 for high-priority tasks).
- Daily streaks tracking.
- Confetti animation when completing tasks.
- Badges for achievements.

### Smart Assistant Panel
- Shows AI suggestions for task scheduling.
- Accept or reject AI-suggested subtasks and time blocks.

### Daily Analysis
- Monitor your productivity.
- See completed tasks and points earned per day.
